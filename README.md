## About the Project

DO SKYMEMORY is a personal embedded systems and quadcopter development project created by Hoang Dinh Do.

The goal is to design, build, program, and test a custom drone while developing practical skills in embedded programming, electronics, wireless communication, and flight control.

Beyond engineering, DO SKYMEMORY represents a personal vision: capturing journeys, preserving meaningful moments, and creating memories from a different perspective.

## Project Objectives

- Develop a custom flight controller using STM32.
- Read motion data from the MPU6050 IMU.
- Implement PID-based flight stabilization.
- Build a wireless remote controller using ESP32 and NRF24L01.
- Control four brushed motors using PWM.
- Test and improve flight stability.
- Explore aerial photography and video recording in future versions.

## Hardware

| Component | Purpose |
|---|---|
| STM32F103C8T6 | Flight controller |
| ESP32 DevKit | Remote controller |
| MPU6050 | Motion sensing |
| NRF24L01+ | Wireless communication |
| Coreless 8520 motors | Propulsion |
| AO3400 MOSFET | Motor control |
| 1S LiPo battery | Power supply |

*Hardware selection and compatibility testing are ongoing.*
